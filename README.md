Vectrion AI — Enterprise Conversational Document Intelligence System
Advanced Retrieval-Augmented Generation (RAG) platform for intelligent multi-document question answering using Hybrid Retrieval, Conversational AI, Semantic Search, and Citation-Grounded Responses.

Unlike traditional keyword search systems, Vectrion AI leverages:
•	Retrieval-Augmented Generation (RAG)
•	Hybrid Retrieval (FAISS + BM25)
•	Conversational Memory
•	Semantic Search
•	Citation-Grounded AI Responses
•	Large Language Models (LLMs)
to provide highly contextual, intelligent, and explainable answers.
